# Codex Subagent Usage

Subagents must be explicitly invoked in prompts.

Examples:

- Use `code-mapper` for repo analysis
- Use `flutter-expert` for UI/UX review
- Use `golang-pro` for backend analysis
- Use `postgres-pro` for DB review
- Use `competitive-analyst` for ERP comparison

Rules:
- Always delegate clearly in prompts
- Always map to milestones
- Always output NEXT PROMPT TO RUN
